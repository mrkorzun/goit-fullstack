# Primary Goal

Become a **Junior Fullstack Developer** with solid understanding of modern web development stack (Frontend + Backend).

### Short-term Goals (HTML-CSS & JavaScript)

- Master semantic HTML5 and modern CSS3 (Flexbox, Grid, Responsive Design)
- Build strong JavaScript fundamentals (ES6+, DOM, Async programming)
- Create pixel-perfect, responsive layouts from Figma designs
- Understand Git workflow and best practices

### Mid-term Goals (React & Next.js)

- Build interactive React applications with state management
- Learn TypeScript for type-safe code
- Understand server-side rendering and modern Next.js patterns
- Implement authentication and API integration

### Long-term Goals (Node.js & Full Stack)

- Develop RESTful APIs with Express.js and MongoDB
- Implement secure authentication & authorization (JWT)
- Deploy full-stack applications to production
- Understand database design and optimization

### Soft Skills

- Write clean, maintainable, and well-documented code
- Communicate effectively in English (IT-English)
- Work with version control and collaborative development
- Problem-solving and debugging skills
